# PROMPT LOG — SRS

## Prompt 01 — Functional Requirements
Susun functional requirements untuk login, master barang, transaksi stok, data penjualan, forecasting, evaluasi model, dashboard, dan laporan.

## Prompt 02 — Non-Functional Requirements
Susun kebutuhan usability, performance, security, reliability, data integrity, maintainability, dan compatibility.

## Prompt 03 — Business Rules
Tentukan aturan transaksi stok, validasi dataset, pemisahan data berdasarkan waktu, pencegahan data leakage, dan penggunaan hasil prediksi.

## Prompt 04 — Random Forest Regression
Tentukan target prediksi, contoh pembentukan fitur historis, pembagian training/testing, serta metrik MAE, RMSE, dan MAPE.

## Prompt 05 — Traceability
Hubungkan User Story dengan Functional Requirement dan Business Rule yang sesuai.

## Catatan
Prompt log ini digunakan sebagai dokumentasi proses penyusunan SRS.
