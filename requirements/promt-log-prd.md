# PROMPT LOG — PRD

## Prompt 01 — Identifikasi Produk
Buat DRAF PRD untuk sistem pengelolaan stok barang berbasis web pada CV. Bay Media dengan fokus prediksi kebutuhan stok menggunakan Random Forest Regression.

## Prompt 02 — Problem Statement
Susun problem statement, fakta permasalahan, dan asumsi yang relevan dengan pengelolaan stok barang dan riwayat penjualan bulanan.

## Prompt 03 — Target User
Identifikasi primary user, secondary user, decision maker, dan kebutuhan masing-masing.

## Prompt 04 — Value Proposition
Jelaskan pain yang dikurangi, gain yang diciptakan, serta alasan Random Forest digunakan sebagai fitur intelligent utama.

## Prompt 05 — KPI dan MoSCoW
Susun KPI yang dapat diuji dan pembagian fitur Must Have, Should Have, Could Have, dan Won't Have untuk prototype.

## Prompt 06 — Intelligent Feature
Jelaskan input, proses, output, evaluasi, serta batasan Random Forest Regression untuk forecasting kebutuhan stok.

## Catatan
Prompt log ini mendokumentasikan proses penyusunan PRD dan bukan bagian dari implementasi program.
